# Primary references

Sources inspected during A0, 2026-11-06:

- System76 Launch source and feature descriptions: https://github.com/system76/launch, pinned in `references/upstream-lock.json`.
- ZMK hardware board integration: https://zmk.dev/docs/hardware-integration/new-board and pinned source in `firmware/config/west.yml`.
- ZMK physical layouts: https://zmk.dev/docs/hardware-integration/physical-layouts.
- ZMK display configuration and current limitations: https://zmk.dev/docs/config/displays and https://zmk.dev/docs/features/displays.
- ZMK Studio: https://zmk.dev/docs/features/studio.
- Raspberry Pi RP2040: https://www.raspberrypi.com/documentation/microcontrollers/microcontroller-chips.html and https://datasheets.raspberrypi.com/rp2040/hardware-design-with-rp2040.pdf.
- TI TS3USB3031 datasheet, SCDS348D: https://www.ti.com/lit/ds/symlink/ts3usb3031.pdf. Pin mapping table 4-1 and selector modes table 6-1 inform the local symbol and firmware.
- Nice!view LCD documentation: https://nicekeyboards.com/docs/nice-view/.
- Kailh PG1350 family: https://www.kailhswitch.com/info/kailh-kl-switches-pg1350-series-23772219.html.
- Kailh Choc socket mechanical drawing: https://www.kailhswitch.com/uploads/15927/files/CPG135001S30.pdf.
- foostan Choc footprint source: https://github.com/foostan/kbd/blob/1f12004a1c9714d0eabec4028c9ae4b259b41562/kicad-footprints/kbd.pretty/keyswitch_choc12_hotswap_1u.kicad_mod.

These references support an engineering starting point. Supplier part availability, final dimensions, USB compliance and physical ergonomic benefits are not established by linking a datasheet.
